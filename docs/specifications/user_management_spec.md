# 用户管理功能规格说明书

## 1. 概述
用户管理功能模块负责系统中用户账户的全生命周期管理，包括创建、查询、修改、删除和状态管理等操作。该模块是系统安全的基础，确保只有合法用户才能访问系统资源。

系统预定义四种用户角色：
- 超级管理员：拥有系统最高权限，可以管理所有功能模块
- 普通用户：只能访问其有权限的文件管理中的文件
- 审计用户：具有查看系统日志和审计记录的权限
- 运维用户：具有系统运维相关权限，如监控、备份等

对于普通用户，系统还需要在Linux操作系统上创建对应的系统用户，用于文件共享协议（如NFS、SMB）的访问控制。这些系统用户的shell设置为/nologin，防止直接登录系统。

## 2. 功能规格

### 2.1 用户创建
- **功能描述**: 管理员可以创建新的用户账户。
- **输入参数**:
  - 用户名 (string, 必填, 唯一): 用于登录系统的标识符，支持字母、数字和下划线，长度3-20个字符。
  - 密码 (string, 必填): 用户登录密码，需满足复杂度要求（至少8位，包含大小写字母、数字和特殊字符）。
  - 角色 (enum, 必填): 用户角色（超级管理员、普通用户、审计用户、运维用户）。
  - 是否启用 (boolean, 必填): 用户账户状态（启用/禁用）。
  - 备注 (string, 可选): 用户的备注信息。
- **处理流程**:
  1. 验证输入参数的合法性。
  2. 检查用户名是否已存在。
  3. 对密码进行加密存储（使用bcrypt等加密算法）。
  4. 生成用户唯一ID。
  5. 设置注册时间为当前时间。
  6. 将用户信息保存到数据库。
  7. 如果创建的是普通用户，则在Linux系统上创建对应的系统用户，设置shell为/nologin。
  8. 返回创建结果。
- **输出结果**:
  - 成功: 返回用户基本信息和创建时间。
  - 失败: 返回错误码和错误信息（如用户名已存在、参数不合法、Linux用户创建失败等）。
- **异常处理**:
  - 输入参数不合法时，返回相应的错误信息。
  - 数据库操作失败时，返回系统错误信息。
  - Linux系统用户创建失败时，回滚数据库操作并返回相应的错误信息。

### 2.2 用户查询
- **功能描述**: 支持按不同条件查询用户列表，支持分页。
- **输入参数**:
  - 用户名 (string, 可选): 模糊匹配用户名。
  - 角色 (enum, 可选): 精确匹配角色（超级管理员、普通用户、审计用户、运维用户）。
  - 状态 (enum, 可选): 用户状态（启用/禁用）。
  - 页面大小 (int, 可选, 默认20): 每页显示的用户数量。
  - 页码 (int, 可选, 默认1): 当前页码。
- **处理流程**:
  1. 根据输入参数构建查询条件。
  2. 从数据库中查询符合条件的用户列表。
  3. 对查询结果进行分页处理。
  4. 返回用户列表和分页信息。
- **输出结果**:
  - 成功: 返回用户列表（不包含密码）和分页信息（总数量、当前页、页面大小）。
  - 失败: 返回错误码和错误信息。
- **异常处理**:
  - 数据库操作失败时，返回系统错误信息。

### 2.3 用户详情
- **功能描述**: 查看用户的详细信息。
- **输入参数**:
  - 用户ID (string, 必填): 用户的唯一标识符。
- **处理流程**:
  1. 根据用户ID从数据库中查询用户详细信息。
  2. 查询用户关联的角色信息。
  3. 返回用户详细信息。
- **输出结果**:
  - 成功: 返回用户详细信息（不包含密码）和关联角色列表。
  - 失败: 返回错误码和错误信息（如用户不存在）。
- **异常处理**:
  - 用户不存在时，返回相应的错误信息。
  - 数据库操作失败时，返回系统错误信息。

### 2.4 用户修改
- **功能描述**: 管理员可以修改用户的基本信息，包括密码重置。
- **输入参数**:
  - 用户ID (string, 必填): 用户的唯一标识符。
  - 角色 (enum, 可选): 用户角色（超级管理员、普通用户、审计用户、运维用户）。
  - 是否启用 (boolean, 可选): 用户账户状态（启用/禁用）。
  - 备注 (string, 可选): 用户的备注信息。
  - 新密码 (string, 可选): 用户新密码，需满足复杂度要求。
- **处理流程**:
  1. 验证用户ID是否存在。
  2. 验证可选参数的合法性。
  3. 如果提供了新密码，则对新密码进行加密。
  4. 更新用户信息到数据库。
  5. 返回更新结果。
- **输出结果**:
  - 成功: 返回更新后的用户基本信息。
  - 失败: 返回错误码和错误信息（如用户不存在、参数不合法等）。
- **异常处理**:
  - 用户不存在时，返回相应的错误信息。
  - 输入参数不合法时，返回相应的错误信息。
  - 数据库操作失败时，返回系统错误信息。

### 2.5 用户删除
- **功能描述**: 管理员可以删除用户。
- **输入参数**:
  - 用户ID (string, 必填): 用户的唯一标识符。
- **处理流程**:
  1. 验证用户ID是否存在。
  2. 确认是否删除（前端需要二次确认）。
  3. 从数据库中删除用户信息。
  4. 删除用户关联的角色信息。
  5. 如果删除的是普通用户，则同时删除Linux系统上对应的系统用户。
  6. 返回删除结果。
- **输出结果**:
  - 成功: 返回删除成功的信息。
  - 失败: 返回错误码和错误信息（如用户不存在、Linux用户删除失败等）。
- **异常处理**:
  - 用户不存在时，返回相应的错误信息。
  - 数据库操作失败时，返回系统错误信息。
  - Linux系统用户删除失败时，记录日志并返回相应的警告信息。

### 2.6 用户状态管理
- **功能描述**: 支持启用/禁用用户账户。
- **输入参数**:
  - 用户ID (string, 必填): 用户的唯一标识符。
  - 状态 (enum, 必填): 用户状态（启用/禁用）。
- **处理流程**:
  1. 验证用户ID是否存在。
  2. 更新用户状态到数据库。
  3. 返回状态更新结果。
- **输出结果**:
  - 成功: 返回更新后的用户状态信息。
  - 失败: 返回错误码和错误信息（如用户不存在）。
- **异常处理**:
  - 用户不存在时，返回相应的错误信息。
  - 数据库操作失败时，返回系统错误信息。

## 3. 非功能规格
- **安全性**: 
  - 用户密码必须加密存储。
  - 所有操作需要管理员权限验证。
  - 敏感操作（如删除、密码重置）需要二次确认。
- **性能**: 
  - 用户查询响应时间不超过1秒。
  - 用户创建、修改、删除操作响应时间不超过500毫秒。
- **可用性**: 
  - 提供友好的管理界面。
  - 提供详细的错误信息提示。
