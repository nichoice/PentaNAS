# PNAS 使用手册

## 系统简介

PNAS (Personal Network Attached Storage) 是一个功能强大的个人网络存储系统，致力于提供安全、高效、私有的网络存储解决方案。系统采用Go语言开发，基于现代化的微服务架构，集成了AI智能文件管理、存储协议支持、系统监控等丰富功能。

## 快速开始

### 系统启动

1. **启动服务**
   ```bash
   sudo ./pnas server
   ```

2. **访问Web界面**
   - 打开浏览器访问：`http://localhost:8080`
   - API文档：`http://localhost:8080/swagger/index.html`

3. **默认登录信息**
   - 用户名：`admin`
   - 密码：`admin123456`

   > ⚠️ **安全提醒**：首次登录后请立即修改默认密码！

## 核心功能使用指南

### 1. 文件存储服务

#### 1.1 文件管理
- **上传文件**：通过Web界面拖拽或点击上传按钮
- **下载文件**：点击文件名或右键选择下载
- **预览文件**：支持图片、文档、视频的在线预览
- **文件搜索**：使用搜索框快速定位文件

#### 1.2 文件夹操作
- **创建文件夹**：右键空白区域选择"新建文件夹"
- **重命名**：右键文件/文件夹选择"重命名"
- **移动文件**：拖拽文件到目标文件夹
- **删除文件**：选中文件后按Delete键或右键删除

#### 1.3 文件共享
- **创建分享链接**：右键文件选择"分享"
- **设置访问权限**：可设置密码保护、有效期等
- **管理分享**：在分享管理页面查看和管理所有分享

#### 1.4 版本控制
- **查看历史版本**：右键文件选择"版本历史"
- **恢复版本**：选择历史版本点击"恢复"
- **版本比较**：对比不同版本的差异

#### 1.5 回收站
- **恢复文件**：在回收站中选择文件点击"恢复"
- **彻底删除**：在回收站中选择文件点击"彻底删除"
- **清空回收站**：点击"清空回收站"按钮

### 2. AI智能文件管理

#### 2.1 智能文件分类
- **自动分类**：系统根据文件内容自动分类
- **智能标签**：为文件自动生成关键词标签
- **内容聚类**：自动识别相似内容的文件分组
- **重复文件检测**：智能识别重复文件并提供清理建议

#### 2.2 智能搜索
- **语义搜索**：支持自然语言搜索
- **多模态搜索**：支持文本、图像内容搜索
- **OCR文本提取**：自动提取图片和PDF中的文本
- **内容摘要**：自动生成文档摘要

#### 2.3 媒体智能处理
- **图像识别**：自动识别图片内容并添加标签
- **人脸检测**：识别照片中的人物
- **视频分析**：生成视频内容时间轴
- **音频转文本**：将语音文件转换为文本

### 3. iSCSI块存储服务

#### 3.1 iSCSI Target管理
- **创建Target**：在存储管理页面点击"新建iSCSI Target"
- **配置认证**：设置CHAP认证用户名和密码
- **访问控制**：配置允许访问的客户端IP地址

#### 3.2 LUN管理
- **创建LUN**：选择文件型、块设备型或内存型LUN
- **配置容量**：设置LUN的存储容量
- **性能调优**：配置缓存和I/O参数

#### 3.3 客户端连接
- **Windows客户端**：
  ```cmd
  iscsicli QAddTargetPortal <服务器IP> 3260
  iscsicli ListTargets
  iscsicli QLoginTarget <target_name>
  ```

- **Linux客户端**：
  ```bash
  sudo iscsiadm -m discovery -t st -p <服务器IP>:3260
  sudo iscsiadm -m node --login
  ```

### 4. 对象存储服务

#### 4.1 存储桶管理
- **创建存储桶**：在对象存储页面点击"新建存储桶"
- **配置权限**：设置公开/私有访问权限
- **生命周期策略**：配置自动删除过期对象

#### 4.2 对象操作
- **上传对象**：通过API或Web界面上传文件
- **设置元数据**：为对象添加自定义元数据
- **版本管理**：启用对象版本控制

#### 4.3 S3兼容API
```bash
# 使用AWS CLI访问
aws s3 --endpoint-url=http://localhost:8080 ls
aws s3 --endpoint-url=http://localhost:8080 cp file.txt s3://mybucket/
```

### 5. 网络协议支持

#### 5.1 SMB/CIFS共享
- **创建SMB共享**：在网络共享页面添加SMB共享
- **Windows访问**：在资源管理器中输入 `\\<服务器IP>\<共享名>`
- **Linux挂载**：
  ```bash
  sudo mount -t cifs //<服务器IP>/<共享名> /mnt/share -o username=<用户名>
  ```

#### 5.2 FTP/SFTP服务
- **启用FTP**：在服务配置中启用FTP服务
- **客户端连接**：
  ```bash
  ftp <服务器IP>
  # 或使用SFTP
  sftp <用户名>@<服务器IP>
  ```

#### 5.3 WebDAV服务
- **启用WebDAV**：在服务配置中启用WebDAV
- **客户端访问**：在文件管理器中添加网络位置 `http://<服务器IP>:8080/webdav`

### 6. 备份和恢复

#### 6.1 自动备份配置
- **创建备份任务**：在备份管理页面点击"新建备份任务"

#### 6.2 快照管理

#### 6.3 灾难恢复

- **恢复向导**：使用恢复向导快速恢复系统
- **验证恢复**：验证恢复数据的完整性

### 7. 用户和权限管理

#### 7.1 用户管理

## 高级配置

### 1. 系统配置文件

主要配置文件位于 `config/` 目录：
- `app.yaml`：应用主配置文件
- `database.yaml`：数据库配置
- `storage.yaml`：存储配置

### 2. 环境变量配置

重要环境变量：
```bash
export PNAS_CONFIG_PATH=/path/to/config
export PNAS_DATA_PATH=/path/to/data
export PNAS_LOG_LEVEL=info
```

### 3. 数据库配置

支持SQLite和MySQL数据库：
```yaml
database:
  type: sqlite  # 或 mysql
  host: localhost
  port: 3306
  name: pnas
  username: root
  password: password
```

### 4. 存储池配置

配置存储池和卷组：
```yaml
storage:
  pools:
    - name: "default"
      path: "/data/storage"
      type: "local"
```

## 常见问题解答

### Q: 忘记管理员密码怎么办？
A: 可以通过命令行重置密码：
```bash
./pnas reset-password --username admin --password newpassword
```

### Q: 如何扩容存储空间？
A: 1. 添加新磁盘到系统
   2. 在存储管理页面添加到卷组
   3. 扩展逻辑卷容量

### Q: 系统支持多少并发用户？
A: 取决于硬件配置，推荐配置下可支持100+并发用户

### Q: 如何备份系统配置？
A: 使用命令：
```bash
./pnas backup-config --output /path/to/backup
```

### Q: 系统日志存储在哪里？
A: 日志文件位于 `logs/` 目录，包括系统日志、访问日志和错误日志

## 命令行工具

### 基本命令
```bash
# 启动服务器
./pnas server

# 查看版本
./pnas version

# 数据库迁移
./pnas migrate

# 重置密码
./pnas reset-password --username <用户名> --password <新密码>

# 备份配置
./pnas backup-config --output <备份路径>

# 系统检查
./pnas check
```

### 存储管理命令
```bash
# 查看存储状态
./pnas storage status

# 创建逻辑卷
./pnas storage create-lv --name <卷名> --size <大小>

# 扩容逻辑卷
./pnas storage extend-lv --name <卷名> --size <新大小>
```
