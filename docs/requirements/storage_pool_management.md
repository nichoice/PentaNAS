# 存储池管理功能需求文档

## 1. 概述
存储池管理模块支持创建和管理基于OpenZFS和LVM两种架构的存储池。存储池是虚拟化存储的基础，可以将多个物理磁盘组合成一个逻辑单元，提供更好的存储管理能力。

## 2. 功能需求

### 2.1 OpenZFS存储池管理
- **创建存储池**: 
  - 支持从磁盘管理模块选择多个磁盘创建OpenZFS存储池。
  - 支持不同的RAID级别（如RAID-Z1, RAID-Z2, RAID-Z3）。
  - 支持设置存储池名称、挂载点等属性。
- **存储池列表**: 
  - 展示所有OpenZFS存储池的基本信息，包括名称、状态、容量、使用率等。
- **存储池详情**: 
  - 查看存储池的详细信息，包括配置、设备状态、健康状况等。
- **存储池操作**:
  - 启动/停止存储池。
  - 扩展存储池（添加更多磁盘）。
  - 删除存储池（需要确认）。
  - 重命名存储池。
  - 查看存储池的I/O统计信息。

### 2.2 LVM存储池管理
- **创建存储池**: 
  - 支持从磁盘管理模块选择多个磁盘创建LVM物理卷(PV)。
  - 支持创建卷组(VG)并将PV加入VG。
  - 支持设置VG名称等属性。
- **存储池列表**: 
  - 展示所有LVM卷组的基本信息，包括名称、状态、容量、使用率等。
- **存储池详情**: 
  - 查看卷组的详细信息，包括包含的PV、逻辑卷(LV)列表、健康状况等。
- **存储池操作**:
  - 扩展卷组（添加更多PV）。
  - 删除卷组（需要确认，且必须先删除所有LV）。
  - 重命名卷组。
  - 查看卷组的I/O统计信息。

### 2.3 存储池监控
- **状态监控**: 实时监控存储池的健康状态和性能指标。
- **容量预警**: 当存储池使用率超过阈值时触发告警。
- **故障检测**: 检测存储池中的磁盘故障并通知管理员。

## 3. 非功能需求
- **稳定性**: 存储池操作需要高度稳定，防止数据丢失。
- **兼容性**: 同时支持OpenZFS和LVM两种架构，提供统一的管理接口。
- **安全性**: 存储池操作需要管理员权限，并记录操作日志。
